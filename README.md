# صِلة 🤟 — محادثة بالصور

تطبيق ويب (PWA) يحوّل الكلام المنطوق إلى **صور متحركة بسيطة** تظهر واحدة بعد الأخرى كقصة قصيرة،
لمساعدة الأشخاص الصم — خاصة كبار السن الذين لا يعرفون القراءة — على فهم ما يقوله من حولهم.

## المزايا
- 🎤 **استماع:** تعرّف على الكلام (الدارجة الجزائرية، الفصحى، الفرنسية، الإنجليزية) وتحويله فوراً إلى صور متحركة.
- 🎬 **شاشة كاملة للأم:** صور فقط، كبيرة، تتكرر تلقائياً.
- 🤖 **ذكاء اصطناعي (اختياري):** مع مفتاح Claude API يفهم معنى الجملة كاملة ويختار 1–5 صور وحركة مناسبة لكل صورة.
- 📖 **قاموس مدمج:** ~200 كلمة بالدارجة والفصحى والفرنسية — يعمل دون إنترنت.
- 👵 **لوحة أمي:** صور جاهزة تشير إليها (ألم، جوع، دواء، أماكن…) + زر طوارئ.
- 💬 سجل المحادثة، تكبير الخط، وضع التباين العالي.
- 📲 قابل للتثبيت على الهاتف كتطبيق، ويفتح دون إنترنت.

## التشغيل
التطبيق منشور على GitHub Pages:
`https://graphicprodz-png.github.io/sila/`

افتح الرابط في **Google Chrome** على الهاتف ← القائمة ⋮ ← **تثبيت التطبيق / إضافة إلى الشاشة الرئيسية**.

> التعرّف على الكلام يحتاج Chrome أو Edge (أو Safari الحديث)، واتصالاً بالإنترنت، وإذن الميكروفون.

## الملفات
| الملف | الدور |
|---|---|
| `index.html` | التطبيق كاملاً (واجهة + قاموس + منطق) |
| `manifest.webmanifest` | تعريف التطبيق للتثبيت على الهاتف |
| `sw.js` | العمل دون إنترنت |
| `icons/` | أيقونات التطبيق |

## إضافة كلمات للقاموس
في `index.html` ابحث عن `const RAW = [` وأضف سطراً بهذا الشكل:
```js
["كلمة1|كلمة2|مرادف","🖼️",""],
```
النوع (الخانة الثالثة) اختياري: `feel` مشاعر، `need` حاجة، `q` سؤال، `urgent` عاجل.

## تطبيق أندرويد (APK)
يُبنى الـ APK **تلقائياً** على GitHub Actions مع كل تحديث (`.github/workflows/android.yml`)،
ويُنشر في صفحة **Releases**. رابط ثابت لآخر نسخة:

`https://github.com/graphicprodz-png/sila/releases/latest/download/sila.apk`

- مجلد `android/` غلاف أندرويد خفيف (WebView) يعرض نفس `index.html`.
- التعرّف على الكلام يتم عبر خدمة الهاتف نفسها (SpeechRecognizer) لأن WebView لا يدعم Web Speech API.
- التوقيع ثابت (`android/app/debug.keystore`)، فكل نسخة جديدة تُثبَّت فوق القديمة.
- يحتاج الهاتف تطبيق **Google** (خدمة التعرّف على الكلام) مع حزمة العربية.
